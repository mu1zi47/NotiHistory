# NotiHistory

NotiHistory — приложение для Android на Flutter с нативной логикой на Kotlin, которое сохраняет уведомления в локальную историю. Находите нужные сообщения, читайте полный текст и возвращайтесь к уведомлениям, даже если они уже исчезли из шторки.

## Скачать

Чтобы установить приложение, откройте раздел релизов:

[![Скачать APK](https://img.shields.io/badge/Скачать_APK-7760DB?style=for-the-badge&logo=android&logoColor=white)](https://github.com/mu1zi47/NotiHistory/releases)

Выберите файл `.apk` в **Assets** нужного релиза. Если APK ещё не опубликован, его можно собрать из исходников по инструкции ниже.

Перед установкой:

- Используйте устройство Android: на других платформах сохранение чужих уведомлений недоступно.
- Если Android запросит разрешение на установку из выбранного источника, включите его для скачанного APK.

## Для пользователей

После установки откройте NotiHistory, нажмите **Включить сохранение** и разрешите **доступ к уведомлениям** в настройках Android.

Новые уведомления начнут появляться в истории. Экран приложения можно закрыть: сохранением занимается нативный Android-сервис.

## Основные возможности

- Локальная история уведомлений, которая сохраняется после повторного запуска приложения.
- Поиск по имени приложения, package name, заголовку и тексту уведомления.
- Поддержка кириллицы и поиска без учёта регистра.
- Фильтрация по приложению и периоду: всё время, сегодня или последние 7 дней.
- Просмотр полного текста и копирование содержимого.
- Удаление отдельных записей свайпом.
- Очистка всей истории с подтверждением.

## Удобные мелочи

- Иконки приложений в ленте и фильтрах.
- Загрузка истории страницами по мере прокрутки.
- Обновление ленты при поступлении уведомлений.
- Повторное обновление активного уведомления с тем же содержимым не создаёт дубликат.
- Отдельные состояния пустой истории, отсутствия доступа и подключения сервиса.

## Приватность

- История хранится на устройстве в SQLite.
- Нет облака, рекламы и аналитики.
- В release-сборке нет разрешения на доступ к интернету.
- Резервное копирование и перенос базы отключены.
- Старые записи остаются в истории, пока вы не удалите их самостоятельно.

## Разрешения и настройка устройства

Для сохранения истории приложению нужен специальный **доступ к уведомлениям** Android. Разрешение на отправку собственных уведомлений для этой функции не требуется.

На некоторых телефонах для приложения, установленного из APK, сначала нужно разрешить **ограниченные настройки** в системной карточке приложения. Ограничения фоновой работы производителя могут влиять на сохранение уведомлений.

## Известные ограничения

- Приложение не восстанавливает уведомления, удалённые до предоставления доступа.
- Принудительная остановка, отозванный доступ, ограничения производителя или нехватка места могут привести к пропускам.
- После принудительной остановки снова откройте приложение; иногда нужно повторно включить доступ к уведомлениям.
- При переподключении сервиса доступны только уведомления, которые ещё находятся в шторке.
- После перезагрузки работа сервиса зависит от Android и разблокировки устройства.
- Android 15+ может скрывать одноразовые коды и другой чувствительный текст.
- Автоматического удаления старых записей нет: база растёт до ручной очистки.

## Как это работает

`NotificationCaptureService` использует Android `NotificationListenerService` и записывает уведомления в SQLite независимо от Flutter-экрана. Интерфейс получает историю через MethodChannel и обновления через EventChannel.

Сохраняется доступный текст опубликованных версий уведомлений, включая развёрнутый текст и сообщения MessagingStyle. Время в ленте — время сохранения; в подробностях доступно время публикации Android.
